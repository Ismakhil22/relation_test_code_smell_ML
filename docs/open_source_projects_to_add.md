# Projets open source Java à ajouter au dataset

Liste de candidats à forte visibilité GitHub, à cloner dans `dataset/projects` puis à faire passer dans le même pipeline PMD/TestSmellDetector. Les étoiles sont indicatives et datées du 23 juin 2026, car elles évoluent continuellement.

| Projet | Dépôt GitHub | Étoiles approx. | Pourquoi l'ajouter |
|---|---|---:|---|
| Elasticsearch | <https://github.com/elastic/elasticsearch> | 77k | Gros moteur de recherche Java avec beaucoup de tests et de modules. |
| OkHttp | <https://github.com/square/okhttp> | 47k | Client HTTP JVM/Android très populaire, suite de tests riche. |
| Apache Dubbo | <https://github.com/apache/dubbo> | 41k | Framework RPC/microservices Java, code applicatif et tests distribués. |
| Guava | <https://github.com/google/guava> | 50k+ | Bibliothèques core Java Google, API variées et tests unitaires nombreux. |
| Mockito | <https://github.com/mockito/mockito> | 15k+ | Framework de test Java ; intéressant pour comparer smells de code de test. |
| JUnit 5 | <https://github.com/junit-team/junit5> | 6k+ | Infrastructure de test Java elle-même, utile pour les patterns de tests. |
| Netty | <https://github.com/netty/netty> | 33k+ | Framework réseau Java haute performance avec tests de concurrence. |
| Apache Kafka | <https://github.com/apache/kafka> | 30k+ | Plateforme streaming JVM, grand volume de code et tests d'intégration. |
| Apache Cassandra | <https://github.com/apache/cassandra> | 9k+ | Base distribuée Java avec architecture complexe et tests nombreux. |
| Apache Pulsar | <https://github.com/apache/pulsar> | 14k+ | Messaging/streaming Java, nombreux modules et tests. |

> Important : ne scanne pas `dataset/projects` pour construire cette liste ; clone uniquement les dépôts choisis puis lance les scripts existants projet par projet.
